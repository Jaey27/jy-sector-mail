개인정보처리방침 — JY Sector Mail

  • 개인 1인용 도구입니다. 계정 소유자 본인만 사용합니다.
  • Gmail 읽기 전용 권한(gmail.readonly)으로 StreetSignal 뉴스레터 메일만 읽습니다.
  • 읽은 내용은 소유자 본인의 요약에만 쓰며, 외부로 공유하거나 판매하지 않습니다. 요약은 소유자 본인 계정의 AI 도구로 만듭니다.
  • 인증 토큰은 소유자 개인 Mac에만 저장합니다.
  • 삭제를 요청하면 토큰을 폐기합니다. Google 계정 → 보안 → 타사 액세스에서 언제든 권한을 철회할 수 있습니다.

Privacy Policy

  • Single-user personal tool used only by the account owner.
  • Reads only StreetSignal newsletter emails via the read-only Gmail scope (gmail.readonly).
  • Data is used only for the owner's own summaries (made with the owner's own AI tool account); it is never shared with others or sold.
  • Auth tokens are stored only on the owner's personal Mac.
  • Tokens are revoked on request; access can be revoked anytime in Google Account → Security → Third-party access.

Google API Services User Data Policy, including the Limited Use requirements, applies.
